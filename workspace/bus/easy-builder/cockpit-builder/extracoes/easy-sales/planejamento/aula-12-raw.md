**RESULTADO: Definição da Solução e Big Idea**
**PLATAFORMA:** Geral (Bloco de notas ou Chat)
**AÇÕES:**
*   **Identificar as dores e desejos reais do cliente ideal**
    Como fazer:
    1.  Mapear o que o cliente não tem hoje (Tempo, Dinheiro ou Segurança).
    2.  Identificar onde o tempo do cliente é desperdiçado (atendimento ruim, retrabalho, necessidade de supervisionar profissionais incompetentes).
    3.  Descobrir o incentivo real do cliente (ex: agradar a esposa, ter tempo para os filhos) através de conversas e relacionamento próximo.
*   **Escrever a promessa/solução em poucas palavras**
    Como fazer:
    1.  Criar uma linha que foque na solução e não apenas no entregável técnico (ex: "te faço ser lembrado" em vez de "faço landing pages").
    2.  Estruturar a frase para que o cliente entenda que você resolve o problema dele e evita problemas futuros.
    3.  Organizar a comunicação para atrair o público específico e repelir clientes indesejados.
**Contexto da aula:** "A solução não é o entregável... o foco deve ser na solução".
**DEPENDE DE:** nada
**REFERENCIA CRUZADA:** PILAR: Posicionamento > Definição de Persona.

**RESULTADO: Estrutura de Produtos e Esteira**
**PLATAFORMA:** Geral
**AÇÕES:**
*   **Listar todos os entregáveis técnicos disponíveis**
    Como fazer:
    1.  Relacionar todos os serviços que você tem capacidade de executar (Landing Page de venda, captura, obrigado, checkout, anúncios, área de membros, etc.).
*   **Criar pacotes de produtos através dos entregáveis**
    Como fazer:
    1.  Agrupar serviços para criar ofertas específicas: Pacote de Lançamento (Captura + Venda + Obrigado + Cronograma + Checkout + Área de Membros), Pacote de Posicionamento High Ticket ou Pacote de Advocacia Online.
    2.  Definir o produto "Popstar" (Vaca leiteira): o serviço que tem alta demanda, dá lucro e é rápido de fazer (ex: páginas de captura, venda e obrigado).
*   **Definir estratégias de Upsell, Cross-sell e Down-sell**
    Como fazer:
    1.  Planejar um produto de maior valor para oferecer após a primeira venda (Upsell), como uma consultoria de branding.
    2.  Definir produtos complementares (Cross-sell), como planos de hospedagem ou suporte recorrente.
    3.  Criar uma versão simplificada do serviço (Down-sell) para não perder a venda caso o cliente não tenha orçamento para o pacote completo.
**Contexto da aula:** "Separem o que vocês entregam e criem os seus produtos através dos entregáveis".
**DEPENDE DE:** Lista de entregáveis pronta.
**REFERENCIA CRUZADA:** PILAR: Técnicas de Venda > Ancoragem de preço.

**RESULTADO: Material de Entrega de Alto Valor (Overdelivery)**
**PLATAFORMA:** Google Drive / PDF
**AÇÕES:**
*   **Montar um PDF de entrega padrão**
    Como fazer:
    1.  Incluir no documento todos os acessos de hospedagem e WordPress.
    2.  Adicionar instruções claras sobre como instalar pixels de rastreamento corretamente.
    3.  Listar os links da pasta do Drive com todos os arquivos organizados.
*   **Organizar a pasta de arquivos editáveis para o cliente**
    Como fazer:
    1.  Disponibilizar os arquivos PSD (Photoshop) e identidades visuais modificadas.
    2.  Criar um usuário padrão no WordPress para o cliente antes mesmo dele solicitar.
**Contexto da aula:** "Entregue mais no seu produto... isso gera um valor do caralho para o cliente".
**DEPENDE DE:** Projeto finalizado.
**REFERENCIA CRUZADA:** PILAR: Entrega > Consistência Visual.

**RESULTADO: Análise de Engenharia Reversa (Estudo de Lançamento)**
**PLATAFORMA:** Facebook Ads Library / Site Map / YouTube
**AÇÕES:**
*   **Mapear o funil de um lançamento real**
    Como fazer:
    1.  Pesquisar anúncios de players do mercado na Biblioteca de Anúncios do Facebook.
    2.  Utilizar o comando "/sitemap.xml" na URL do site do cliente/concorrente para identificar todas as páginas utilizadas no lançamento (captura, cronograma, blog, etc.).
    3.  Desenhar o fluxo do funil: Anúncio > Captura > Obrigado > Grupo de WhatsApp > CPLs > Checkout > Página de Vendas.
**Contexto da aula:** "Maximizem a capacidade de vocês de fazer engenharia reversa... isso vai colocar vocês à frente do tempo".
**DEPENDE DE:** nada
**REFERENCIA CRUZADA:** nada

### **DECISÕES PENDENTES**
1.  **Definição do Cliente Ideal:** Escolher especificamente para quem a solução será direcionada (ex: infoprodutores, advogados, lançamentos femininos).
2.  **Escolha do Produto Popstar:** Decidir qual serviço será o carro-chefe para gerar fluxo de caixa rápido (80/20).
3.  **Modelo de Recorrência:** Decidir se oferecerá manutenção, suporte ou planos de hospedagem mensal.

### **PRÉ-REQUISITOS**
1.  **Acesso à Biblioteca de Anúncios do Facebook (Meta Ads):** Para pesquisa de referências.
2.  **Conta no Google Drive / Ferramenta de PDF:** Para organizar os entregáveis extras.
3.  **Hospedagem/WordPress:** Conhecimento para criar usuários e acessos para o cliente.
