# Mockups

Protótipos em HTML puro, feitos antes de virar componente. Vieram da área de
trabalho em 2026-07-30 — estavam soltos lá, fora de qualquer controle de versão.

**Não são código de produção e nada em `src/` depende deles.** São a referência
visual de para onde a tela vai: quando o componente React nasce, o mockup vira
histórico e não precisa mais ser atualizado.

| arquivo | o que é |
|---|---|
| `cockpit-predio.html` | o prédio dos 4 pilares — versão atual (30/07, 14h34) |
| `cockpit-predio-rascunho-1.html` | primeira tentativa do prédio (30/07, 09h01) |
| `cockpit-predio-rascunho-2.html` | segunda tentativa (30/07, 09h09) |
| `cockpit-predios.html` | variação com os prédios lado a lado |
| `mockup-obra.html` | a Obra — origem do que virou `src/components/obra/Obra.tsx` |

Os dois rascunhos chegaram como "cockpit-predio - Copia.html" e
"cockpit-predio - Copia (2).html". Foram renomeados porque espaço e parêntese em
nome de arquivo atrapalham em git, URL e linha de comando — o conteúdo é o
mesmo, e a ordem pela data de modificação foi preservada no nome.
